重新查询已连接 MCP 服务器的工具列表并更新可用工具。

每个服务器返回一条结果：服务器名称、刷新状态、当前工具数量，以及相对于之前可用工具新增或移除的工具名称。当前未连接的服务器报告为 not_connected（此工具不会拨号或重新拨号连接——它仅通过现有连接重新读取工具列表）。

参数：
- server（可选）：要刷新的特定 MCP 服务器的名称。如果未提供，则刷新所有已连接的服务器。
