从页面中提取原始文本内容，优先提取文章内容。非常适合阅读文章、博客文章或其他以文本为主的页面。返回不带 HTML 格式的纯文本。如果你没有有效的标签页 ID，请先使用 tabs_context_mcp 获取可用标签页。
