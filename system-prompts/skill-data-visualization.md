# 数据可视化

图表是**由人阅读、由你执行的**。此技能将"让它看起来好看"变成带检查的过程，因此结果在结构上正确而非凭品味。

**此处的方法是设计系统无关的。** 过程、形式启发式、六项检查或标记规格中没有特定于某个产品的内容。设计系统提供一小组*参数*（其渐变、分类顺序、发散对、状态调色板、纹理、表面、过滤组件）；方法不变地消费它们。**验证过的默认调色板**是参考实例，在 `references/palette.md` 中完整指定。要针对你的品牌，读取该文件的结构并替换其值——不修改其他内容。

> 最重要的习惯：**颜色部分是可计算的，所以要计算它。**
> 永远不要目测调色板是否色盲安全——运行 `scripts/validate_palette.js`。

## 过程——按顺序执行

颜色放在最后。大多数糟糕的图表先选颜色。

1. **选择形式。** 数据的工作是什么——幅度、身份、极性、单一标题、时间变化？工作选择图表类型，有时答案是*不是图表*（统计块或英雄数字）。→ `references/choosing-a-form.md`
2. **按工作分配颜色。** 分类（身份）、顺序（幅度）、发散（极性）或状态（状态）——每个有一条规则。按固定顺序分配分类色相，永不循环。→ `references/color-formula.md`
3. **验证调色板——运行脚本，不要推理 ΔE。** `node scripts/validate_palette.js "<hex,hex,…>" --mode light`（相对于此技能的基础目录——或在图表自己的页面中作为 `<script type="module">` 加载，它从 `<body>` 读取 `data-palette` 并记录 `console.table` 报告）。它返回亮度区间、色度底线、相邻对 CVD 分离、正常视觉底线和对比度的通过/失败。在继续之前修复任何失败项。用该模式的表面重新运行 `--mode dark`。
4. **应用标记规格和间隔。** 细标记、4px 圆角数据端锚定到基线、2px 线、≥8px 标记、填充之间 2px 表面间隙（堆叠段和相邻条形同样）以及重叠标记上 2px 表面环、选择性直接标签。→ `references/marks-and-anatomy.md`
5. **添加悬停层——默认情况下。** HTML/SVG 图表*是*交互式的；在折线/面积图上提供十字线+工具提示，在条形/点/单元格上提供每标记悬停工具提示。唯一跳过的是没有图的纯统计块。命中目标大于标记；过滤器在图表上方一行。→ `references/interaction.md`
6. **最终无障碍检查。** ≥ 2 个序列时始终有图例且 ≤ 4 个也有直接标注（单个序列不需要图例框——标题命名它），因此身份从不单独依赖颜色；存在表格视图；暗色模式是**选中的**——来自相同渐变的自己的步骤，对照暗色表面验证，不是自动翻转；纹理可用于 CVD/打印/强制颜色情况。
7. **渲染并查看它。** 验证器检查颜色，不检查布局——打开或截图输出并在完成前目测检查标签冲突、几何和溢出。

然后对照 **`references/anti-patterns.md`** 检查结果——它是出错内容的目录。如果你的图表匹配某个条目，它就是错的。

## 不可协商项（在每个设计系统中都为真）

- **按固定顺序分配分类色相，永不循环。** 第 9 个序列永远不是生成的色相——它折叠为"其他"、小多图或复合编码。
- **一个轴。** 永远不要双轴图表（两个 y 轴刻度）。两个不同规模的度量→两个图表、小多图或索引到共同基准。*（这是第 #1 图表错误——参见反模式。）*
- **颜色跟随实体，永不跟随其排名。** 改变序列数量的过滤器不得重新绘制幸存者。
- **顺序 = 一种色相，浅→深。发散 = 两种色相 + 中性灰色中点。** 永远不要彩虹；永远不要在发散中点有色相。
- **在发布任何分类调色板之前运行验证器。** CVD ΔE ≥ 8 是目标（OKLab ×100）；6–8 是仅在辅助编码下合法的底线。正常视觉底线低于 15 是硬性失败——全色读者无法区分这对；在相邻对列表上重新分步（辅助编码不能豁免此项）；在 `--pairs all` 下减少序列或分面——参见检查 4。对比度警告要求可见标签或表格视图——不可忽略。
- **细标记；≥ 2 个序列时始终有图例（一个则无），带选择性直接标签（从不在每个点上有数字）；从属网格/轴线。**
- **文本穿戴文本标记，永不使用序列颜色** ——值、标签和图例保持主/次/弱化墨水；旁边的彩色标记承载身份。
- **状态颜色是保留的**（good/warning/serious/critical），永不为"序列 4"重用；它们附带图标 + 标签发布，从不单独使用颜色。

## 插入设计系统

方法是不变的；只有这些参数按系统变化。参考实例——每个值都已填充——是 `references/palette.md`。

| 参数 | 系统提供的内容 |
|------|----------------|
| **渐变** | 调色板绘制的色相刻度（命名步骤） |
| **分类主题** | 固定的色相顺序（命名主题）；默认 + 替代 |
| **顺序色相** | 幅度的默认单色相 |
| **发散对** | 两个暖/冷两极 + 中性中点 |
| **状态调色板** | good / warning / serious / critical — 与分类区分的步骤 |
| **纹理填充** | 一种方向性手绘填充，在 45° / 135° 使用 |
| **表面** | 亮色和暗色图表表面颜色（验证器需要这些） |
| **过滤控件** | 日期范围和维度控件（行为规格在 `interaction.md`） |

要接入新系统：填充这些行，将其渐变输入验证器，让它将每个槽位对齐到最近的通过步骤。结构和规则保持不变。
