# 选择形式

在颜色**之前**决定这个。数据的任务决定形式 — 有时
正确的形式不是图表。

## 它真的是图表吗？

| 数据是… | 使用 | 而非 |
|---|---|---|
| 单个当前值（可能加趋势） | **统计卡片**（值 + 变化量 + 迷你折线图） | 单条条形图 |
| 少量关键数字 | **KPI 行**，多个统计卡片 | 分组条形图 |
| 仪表盘首屏展示的数字 | **主数字**（≥48px，无衬线体） | — |
| 单个比率对比限制值 | **仪表**（同色渐变轨道） | 2 片饼图 |
| 超过约 7 个都承载含义的类别 | **表格**（或表格 + 图表） | 更多颜色 |

如果图表*确实*合适，按任务选择类型：

## 任务 → 类型

| 任务（读者必须做的） | 默认形式 | 颜色任务 |
|---|---|---|
| 比较量值，低→高 | 条形/柱形；网格用**热力图** | 顺序（一个色相） |
| 时间趋势 | 折线；单序列用面积图 | 顺序或 1 种分类色 |
| 区分不同序列 | 分组/堆叠条形，多折线 | **分类** |
| 一个序列是重点，其余是背景 | **强调**（高亮一个，其余灰色） | 1 色相 + 灰 |
| 基线之上/之下；与目标的差值 | 发散条形，或折线对比基线 | 发散 |
| 部分与整体 | **堆叠条形**（多/长名称类别时用水平方向） | 分类 |
| 有序刻度占比（李克特、情感、同意↔不同意） | **发散堆叠条形**，以中立为中心 | 发散 |
| 每项的前→后对比 | 哑铃图 | 1 色相，2 色阶 |

## 表格背后的规则

- **顺序是安全的默认选择。** 一个色相，越深越多。它保持清晰且
  一致，不容易被误读。除非数据的任务明确是*身份*或*极性*，
  否则优先选择它。
- **分类用于序列本身就是主题时** — 它有实际代价：
  可能淹没真正重要的那个数据点。如果故事是"这一个
  上升了"，那是**强调**，不是分类。
- **强调** = 最被低估的形式。一个序列用强调色，其余用
  弱化灰。通常是"让图表更清晰"的诚实答案。
- **纹理是可选表达，不是默认形式。** 它仅在
  无障碍（完整 CVD）、打印/导出和 `forced-colors` 时才获得使用位置。绝不装饰性使用。
  → 参见 `marks-and-anatomy.md`。

## 序列数量阶梯（分类）

| 序列数 | 处理方式 |
|---|---|
| 1–3 | 仅颜色对所有人都舒适；直接标注 |
| 4 | CVD 底线进入 — 直接标注变为强制，而非礼貌 |
| 5–6 | 软上限；图例或小多图 |
| 7–8 | 标记上限；超过后，将尾部折叠为"其他"，分面为小多图，或使用复合编码（色相 × 形状） |

永远不要通过生成更多色相来解决"序列太多"。在 CVD 下，生成的第 9 种色相
与已有的无法区分，并破坏所有检查。
