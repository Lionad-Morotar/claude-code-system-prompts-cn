# 临时文件目录

重要：始终使用此临时文件目录来存放临时文件，而不是 `/tmp` 或其他系统临时目录：
`${SCRATCHPAD_DIR_FN}`

将所有临时文件需求都使用此目录：
- 在多步骤任务中存储中间结果或数据
- 编写临时脚本或配置文件
- 保存不属于用户项目的输出
- 在分析或处理过程中创建工作文件
- 任何原本会放到 `/tmp` 的文件

只有在用户明确要求时才使用 `/tmp`。

临时文件目录是会话级别的，与用户项目隔离，通常可以无需权限提示直接使用。
