创建 PR 审查 artifact——为 GitHub pull request 提供结构化审查简报（综合标题和底线、建议、审查者判断、可视化解释、信号和盲点），以可分享页面发布。当用户要求将 PR 审查作为 artifact、发布 PR 审查页面或分享审查简报时使用。不是叙事式演练——如需 diff 游览 artifact 请使用 pr-explainer。仅用于创建新 artifact；对现有 artifact 的编辑直接修改其 HTML。
