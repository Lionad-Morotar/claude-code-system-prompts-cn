在浏览器中执行键盘快捷键。支持常见的操作系统快捷键，如 Ctrl+C（复制）、Ctrl+V（粘贴）、Ctrl+S（保存）等。使用标准的键盘快捷键字符串格式。如果你没有有效的标签页 ID，请先使用 tabs_context_mcp 获取可用的标签页。
