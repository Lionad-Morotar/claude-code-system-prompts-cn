交互式表格布局：筛选输入框、密集可排序表格（点击列头排序）和行数统计。数据以 JSON 数组嵌入；内置渲染器负责绘制和重新排序。

## 使用方法

1. 从此技能的基础目录（上方列出）读取 `template.html`。
2. 将其复制为起点。将每个 `<!-- SLOT: ... -->` 标记替换为真实内容 — 每个槽位内的注释描述了应填入的内容。每个槽位在注释后还有占位文本（示例标题、示例行、示例值）；也需替换这些文本 — 仅移除注释标记会留下占位内容在发布页面中。
3. 发布前自检填充后的 HTML：无残留 `SLOT` 标记，无遗留占位文本。
4. 使用 `Artifact` 工具发布填充后的 HTML。

**仅限创建。** 编辑现有数据表工件时，直接操作其当前 HTML — 不要重新读取或重新应用此模板。

## 槽位

| 槽位 | 填入内容 |
| --- | --- |
| `TITLE` | 纯文本页面标题，例如"产品目录"。出现**两次** — 靠近顶部的 `<title>` 元素（命名浏览器标签和工件本身）和头部可见的 `<h1>`。两处都需填写。 |
| `COLUMNS` | 列定义 JSON 数组：`{key, label, type}`。`type` 为 `"text"` 或 `"num"`（右对齐，数字排序）。 |
| `ROWS` | 行对象 JSON 数组，每个以列键为键。嵌入完整数据集 — 渲染器处理滚动（大小上限见数据规则）。 |
| `FOOTER_NOTE` | 数据来源和生成时间戳。 |

模板还有一个用于头部范围文本的次要内联槽位 — 在原位标注。

## 数据规则

- `"num"` 列中的值必须是 JSON 数字，而非字符串 — `1234.5`，而非 `"1,234.50"` 或 `"$1,234.50"`。去除货币符号和千位分隔符；将单位放在列标签中（例如"金额 (USD)"）。`"num"` 列中的非数字值（如 `"$1,234.50"` 字符串、布尔值）按原样显示但跳过数字格式化并排到末尾。
- 缺失值为 `null`（或省略键）— 绝不 `0`、`"N/A"` 或 `"-"`。空字符串和仅空白的字符串也算缺失。渲染器将缺失单元格显示为空白并排在最后。
- 日期放在 `"text"` 列中，格式为 ISO-8601（`2026-07-08`），这样字母排序也是时间排序。人类风格日期（"Jul 8, 2026"）排序会出错。
- 两个 JSON 块必须是严格 JSON：双引号、无尾逗号、无注释、无 `NaN`/`Infinity`。
- 在 JSON 字符串值内，将 `</` 转义为 `<\/`，将 `<!--` 转义为 `<\u0021--`（两者都是有效 JSON 并可解析回原文）。未转义时，`</script` 会提前终止脚本块 — 破坏表格并让值的其余部分渲染为活动 HTML — 而 `<!--` 在脚本数据中打开类似 HTML 注释的状态，同样具有破坏效果。
- 数字显示最多 6 位小数。预先将值四舍五入到值得显示的精度 — 混合精度会使右对齐列参差不齐。
- 嵌入完整数据集，最多几千行。超过此限制时，子集或聚合为用户实际会浏览的内容，并在 `FOOTER_NOTE` 中说明被 cut 的内容。

## 在上方重新设计样式

模板的价值在于其工作机制 — 布局、排序、筛选。发布的样式是干净的默认值（每个绘制令牌都有暗色对应值），而非最终外观：当用户请求或主题建议不同感觉时，在其上方重新设计样式。

- 可安全重新设计：整个 `<style>` 块 — 颜色、排版、间距、条纹、圆角。更改调色板令牌时，在其声明的所有四个作用域中更改 — 亮色 `:root` 块、`@media (prefers-color-scheme: dark)` 块、`:root[data-theme="dark"]` 块和 `@media print` 块（打印始终为亮色；遗漏的令牌在纸上会回退到发布的调色板）— 这样重新设计的表格跟随操作系统暗色设置、查看器主题切换和打印。仅在 `:root` 中更改的值会在暗色模式和打印中回退。
- 保持完整：主题结构本身（所有四个作用域，包括媒体块上的 `:where()` 守卫、`color-scheme` 固定和 `@media print` 重新固定块）、表格标记结构、`<script>` 块，以及脚本读取的 id 和类 — `dt`、`dt-filter`、`dt-count`、`arrow`、`sorted`、`num`、`empty`。重命名或移除这些会破坏排序、筛选或主题。

## 注释

- 模板是 **body 片段** — 无 `<!DOCTYPE>`/`<html>`/`<head>`/`<body>` 包装。Artifact 工具在发布时添加自己的骨架。
- 数据放在两个 JSON `<script>` 块中，而非字面 `<tr>` 标记 — 渲染器负责行输出以使排序和筛选生效。
- 筛选输入框匹配所有文本列的子字符串；数字列排除在文本筛选之外。无匹配结果的筛选显示内置的"No rows match"消息 — 不要自行添加。
- 如果不同色相更贴切，调整 `--accent` — 在声明它的每个作用域中（参见上方重新设计样式）。
