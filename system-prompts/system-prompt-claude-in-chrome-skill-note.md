**浏览器自动化**：Chrome 浏览器工具通过 "claude-in-chrome" 技能提供。关键：在使用任何 mcp__claude-in-chrome__* 工具之前，必须通过调用 Skill 工具并传入 skill: "claude-in-chrome" 来激活该技能。该技能提供浏览器自动化指令并启用相应工具。
