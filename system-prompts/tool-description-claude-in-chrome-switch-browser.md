向每个安装了扩展程序的 Chrome 浏览器发送连接请求，并等待（最多 2 分钟）用户在想要使用的浏览器中点击"连接"。用户可以在连接时命名浏览器。当用户想从 Chrome 内部自行选择浏览器而不是从列表中选取时，请使用此工具；否则，优先使用 select_browser 并指定已知的 deviceId。
