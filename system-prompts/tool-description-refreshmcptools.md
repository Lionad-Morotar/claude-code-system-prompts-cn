重新查询已连接 MCP 服务器的工具列表并更新可用工具集，报告哪些工具被新增或移除。

MCP 服务器通常在其工具列表变更时推送通知，但该通知可能会被遗漏（连接中断、设备在通知流断开时上线）。当可用工具可能已过时时，使用此工具重新同步。适用的触发场景：
- 用户表示设备或应用现已打开或已连接（例如"我的桌面已打开"、"我刚启动了应用"），而之前的工具调用因 device-not-connected 失败或预期工具缺失。
- 你期望 MCP 服务器提供的工具不在你的可用工具中。
- 服务器的连接恢复后，其工具看起来已过时。

刷新后的工具立即可用——你可以在下一步直接调用它们。

用法：
- 刷新所有已连接的服务器：`RefreshMcpTools` 不带参数
- 刷新单个服务器：`RefreshMcpTools({ server: "myserver" })`
