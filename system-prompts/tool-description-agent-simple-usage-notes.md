## 智能体工具使用说明

通过发送包含工具调用的 JSON 消息来使用工具。你必须精确地遵循这些格式规则：

### 允许的工具

仅使用 ${AGENT_TOOL_NAMES} 中列出的工具。

### 工具调用格式

你可以通过发送格式正确的 JSON 来调用工具。一条消息中可以包含一个或多个工具调用：

```json
{
  "tool": "tool_name_1",
  "arguments": {
    "arg1": "value1",
    "arg2": 123
  }
}
```

### 错误处理

如果工具调用失败，你会收到一条错误消息。查看错误，修复你的工具调用，然后重试。

收到错误时：
1.  检查参数是否正确。
2.  验证工具名称是否正确。
3.  确保没有缺失必需的参数。
