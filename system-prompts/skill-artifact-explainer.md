教学导向布局：开头说明读者将学到什么，随后是编号步骤，每步将简短的文字说明与视觉元素配对 — 通常是图表，有时是代码块或带注释的示例 — 最后以回顾收尾。

## 使用方法

1. 从此技能的基础目录（上方列出）读取 `template.html`。
2. 将其复制为起点。将每个 `<!-- SLOT: ... -->` 标记替换为真实内容 — 每个槽位内的注释描述了应填入的内容。每个槽位在注释后还有占位文本（示例标题、示例步骤、示例句子）；也需替换这些文本 — 仅移除注释标记会留下占位内容在发布页面中。
3. 发布前自检填充后的 HTML：无残留 `SLOT` 标记，无遗留占位文本。
4. 使用 `Artifact` 工具发布填充后的 HTML。

**仅限创建。** 编辑现有讲解工件时，直接操作其当前 HTML — 不要重新读取或重新应用此模板。

## 风格

模板主体提供两种结构 — 保留一种，删除另一种（及其包装）：

- **编号步骤**（默认）：读者从头到尾跟随的递进。用于概念讲解 — 某事物如何运作。
- **章节**：对系统、变更或架构的巡览，阅读顺序更灵活，代码权重更大。用于 PR 演练、代码库巡览和设计概览。当主题有结构故事时，以一个宽幅架构或流程图开头；在章节内，代码片段通常就是主题本身 — 仅在结构或流程确实需要时才添加图表。

## 槽位

| 槽位 | 填入内容 |
| --- | --- |
| `TITLE` | 讲解的内容，以读者心中的问题表述 — 例如"布隆过滤器如何工作？"标题出现在**两个位置**：靠近顶部的 `<title>` 标签（成为浏览器标签标题）和头部 `<h1>` — 两处都需填写。 |
| `LEDE` | 两到三句话：读者最终将理解什么，以及为什么重要。 |
| `STEPS` | 步骤风格：每个概念或阶段一个 `<li class="step">`。每步有标题、1–3 段简短散文和 `.visual` 块 — 通常是内联 SVG 图表；有时是 `<pre>` 代码示例或带注释的代码片段。每步保持一个核心想法。步骤可以可选的 `<p class="callout">` 旁注结尾 — 陷阱、类比或后续指引。 |
| `SECTIONS` | 章节风格：2–7 个 `<section class="topic">` 块，按材料的接缝切割 — 组合相关材料而非机械分割。每个有 `<h2>`、简短散文和通常是代码片段的 `.visual` 块；可选地以一个宽幅架构图开头整个风格。`callout` 旁注在此同样适用。 |
| `RECAP` | 简短的项目列表，以读者的新词汇重述核心要点。 |

## 视觉元素

- 在步骤风格中，默认使用图表：大多数步骤应包含一个 — 读者从图片中理解结构和流程，先于解析文字。以文字和代码块为主的讲解未充分利用格式。仅当概念确实是符号性的（语法、精确值、比较）时才单独使用 `<pre>` 代码块或小表格 — 此时代码本身比围绕它的图表更有教学效果；当两者都有帮助时，在同一步骤中将图表与简短代码示例配对。（章节风格反转此平衡 — 参见上方风格。）代码放在 `<pre>` 中，而非作为 SVG 内的文本。
- 为每个 SVG 设置固定 `viewBox`，不设 width/height 属性 — 模板负责缩放。
- SVG 文本保持 14–16px，在形状和标签周围留出充足间距；拥挤的图表是最常见的失败。
- 使用简单、一致的视觉词汇：方框表示事物，箭头表示运动或因果，强调色 — `style` 属性中的 `var(--accent)`；`var()` 在裸 SVG 属性中静默失败 — 仅用于当前步骤聚焦的内容。在步骤间保持完全一致，使图表读起来像一幅不断演进的图，而非每次都是新图。
- 通过模板的令牌为每个图表着色，使用 `style` 属性 — 绝不在 SVG 中使用硬编码 hex、命名颜色或 `white`/`black`：`var(--ink)` 用于文本和描边，`var(--ink-soft)` 用于次要标签，`var(--accent)` 用于强调，`var(--card)`（或 `none`）用于方框内部，`var(--bg)` 用于形状需匹配页面的地方。页面根据查看器以亮色或暗色渲染；任何固定颜色都会在其中之一中出问题 — 近黑色文本在暗色上消失，亮色方框填充在暗色上刺眼。
- 为每个 SVG 设置 `role="img"` 和说明其内容的 `aria-label`。

## 注释

- 模板是 **body 片段** — 无 `<!DOCTYPE>`/`<html>`/`<head>`/`<body>` 包装。Artifact 工具在发布时添加自己的骨架。
- 每步的 `.visual` 块是自由形式容器：放入最能说明该步骤的内容（SVG、代码、小表格）。没有内置渲染器 — 直接编写视觉内容。
- 步骤风格：目标 3–6 步。更少则要么是报告要么是章节风格；更多则应拆分。
- 如果不同色相更贴切，调整 `--accent` — 在声明它的每个作用域中更改（亮色 `:root` 块和两个暗色作用域），否则强调色在暗色模式下会回退到发布值。
