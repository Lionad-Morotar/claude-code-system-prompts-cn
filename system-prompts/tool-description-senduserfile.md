向用户发送文件。当文件*就是*交付物时使用此工具——生成的图表、报告、截图、构建产物——并且你希望它被展示出来，而不仅仅是提及。路径可以是绝对路径或相对于当前工作目录。

当一行上下文有帮助时添加 `caption`（"失败的情况是第 42 行"、"之前 vs 之后"）。如果文件本身不言自明则跳过。

在每次调用时设置 `status`。当你主动发起时使用 `proactive`——用户已离开，你希望此消息到达他们的手机（构建产物就绪、报告已生成）。当回复用户刚说的内容时使用 `normal`。

设置 `display` 以选择文件的呈现方式。使用 `'render'` 当用户应该立即在侧面板中内联查看内容时——图表、渲染的 HTML 页面、图表、图像。使用 `'attach'` 当文件是用户会保存并在其他地方打开的——源代码、电子表格、另一个应用的文件——并且内联预览只会是噪音。不设置则让客户端按文件类型自动决定。
