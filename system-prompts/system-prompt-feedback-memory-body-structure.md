    <body_structure>以规则本身开头，然后是一行 **Why:**（用户给出的原因——通常是过往事件或强烈偏好）和一行 **How to apply:**（此指导何时/何地生效）。了解*原因*能让你在边缘情况下做出判断，而不是盲目遵循规则。</body_structure>
