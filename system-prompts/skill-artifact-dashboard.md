运营仪表板的基础样式和可复用组件：KPI 磁贴卡片、规格驱动的折线图渲染器和表格样式，按合理的默认布局排列（KPI 行、主图表、明细表）。模板设定视觉基础 — 不固定最终仪表板的结构或内容。

## 使用方法

1. 从此技能的基础目录（上方列出）读取 `template.html`。
2. 将其复制为起点。将每个 `<!-- SLOT: ... -->` 标记替换为真实内容 — 每个槽位内的注释描述了应填入的内容。从最终输出中移除槽位注释。
3. 然后使仪表板适配数据和需求：添加图表（`dataviz` 技能是设计更丰富或额外可视化的合适伴侣）、重新排序或删除章节、扩展布局网格。槽位是起点而非终点 — 数据可视化的定制化至关重要，卡片系统、渲染器和表格样式是可组合的组件，保留基础样式使结果呈现为统一的设计。
4. 发布前自检：无残留 `SLOT` 标记，无遗留占位文本或值（参见注释）。
5. 使用 `Artifact` 工具发布填充后的 HTML。

**仅限创建。** 编辑现有仪表板工件时，直接操作其当前 HTML — 不要重新读取或重新应用此模板。

## 槽位

| 槽位 | 填入内容 |
| --- | --- |
| `TITLE` | 纯文本页面标题，例如"Q2 收入仪表板"。 |
| `KPI_TILES` | 2–5 个 `.card.kpi` 块 — 每个一个标题数字，可选上/下增量。按含义而非方向为增量着色（参见注释）。 |
| `PRIMARY_CHART_SPEC` | `<script type="application/json" id="primary-chart-spec" data-chart-runtime>` 内的 JSON 规格。支持 `"type"`：line（默认）、bar 或 donut — 多系列规格自动添加图例，可选轴标题和 y 域参数在槽位旁有文档说明。`data-chart-runtime` 属性至关重要（发布时图表注入依赖它 — 请保留）。标准情况填写规格；其他图表类型或更丰富行为，在旁边添加自己的图表。 |
| `BREAKDOWN_ROWS` | 表头 `<th>` 单元格和每行一个 `<tr>`。为数字列添加 `class="num"` 以右对齐。 |
| `FOOTER_NOTE` | 数据来源和生成时间戳。 |

模板还有一些次要的内联槽位（副标题、图表标题、明细标题）— 每个都在原位标注。

## 注释

- 模板是 **body 片段** — 无 `<!DOCTYPE>`/`<html>`/`<head>`/`<body>` 包装。Artifact 工具在发布时添加自己的骨架。
- 图表槽位接受 JSON 规格，而非标记：你输出数据 + 少量参数；模板的 `renderChart()` 负责像素。规格形状在槽位旁的内联文档中有说明。
- **替换每个占位数字 — 绝不捏造。** 每个占位值 — KPI 数字、表格行和图表规格中归零的"REPLACE ME"系列 — 必须替换为真实数据，或移除其整个章节。日期和元数据同理：页脚的数据来源和生成日期来自对话或省略，绝不编造。发布输出不得包含占位或捏造的值。
- **没有时间维度？** 不要编造趋势 — 绝不为本无时间轴的数据捏造时间轴。三条好路径：当形状合适时在图表规格中使用 `"type": "bar"` 或 `"type": "donut"`（确定性，标准形状首选）；当需要规格未涵盖的形状或完全视觉控制时手绘 SVG 或 HTML 图表（`dataviz` 技能帮助设计 — 复用卡片框架和调色板）；或删除图表章节，以 KPI 磁贴和明细表开头。对于任何趋势数据，首选 `"line"`：它是发布页面的图表运行时不可用时唯一仍能绘制的规格类型 — 手绘 SVG 图表无此依赖。
- **格式化数字以便扫描。** KPI 值带单位和 2–3 位有效数字，千位分隔符（如 $1.2M、98.7%、412ms）；百分比最多一位小数。明细表保持大约前十大行，将长尾归入"其他"行。
- **按含义而非方向为增量着色。** `up`/`down` 类选择箭头并默认绿升红降。当下降代表改善时 — 延迟、成本、错误率 — 添加 `good`（或 `bad`）类使颜色表达消息好坏。
- **远离零的窄范围**（例如，正常运行时间在 97% 到 99% 之间波动）在默认零基轴上会被压扁。在图表规格中设置 `y.min`/`y.max` 缩放域，并在图表标题或页脚中提及截断的轴，以免缩放误导。
- **默认样式是起点，而非固定风格。** 调色板内置暗色模式；鼓励后续样式/主题调整 — 将 `--accent` 调向主题（优先使用已发布的调色板中的另一个令牌以保持页面一致性；在声明它的每个作用域中更改 — 亮色 `:root` 块和两个暗色作用域 — 否则暗色模式下会回弹），调整表面，或完全重新设计。重新设计或手绘 SVG 图表时，通过 `style` 属性中的 CSS 自定义属性传递颜色（`var()` 在裸 SVG 展示属性中静默失败），并确保每个自定义颜色在亮色和暗色下均可读 — 硬编码的近黑色描边在暗色背景上会消失。
