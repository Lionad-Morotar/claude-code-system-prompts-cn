在当前光标位置释放鼠标左键。调用此工具时，最前台的应用程序必须在会话允许列表（allowlist）中，否则此工具会返回错误且不执行任何操作。与 left_mouse_down 配对使用。即使按钮当前未处于按住状态，调用也是安全的。
