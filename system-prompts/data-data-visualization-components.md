# 组件 — 图表的构成部分

图表由这些部分构建，以纯 HTML/SVG 组装。Tier 0 是
一切挂载的基础；System 层使方法可移植（并且本身就是此 skill）。

## Tier 0 — 基础
- **颜色角色** — 分类（8 × 亮/暗）、顺序渐变、发散对、
  状态（4）、弱化/"其他"、灰度图表构件（轴/网格/标签/表面）。
  在 HTML 顶部定义为 CSS 自定义属性 — 参见 `palette.md`。
- **纹理填充** — 方向性填充 + 45°/135° 旋转。
- **图表容器** — 一个 `<figure>`（或卡片 `<div>`），负责响应式
  尺寸、标题/说明文字和**表格视图切换**（每个图表的无障碍副本）。
  **任何固定高度都包含 x 轴区域**（绘图高度 + 轴标签），
  使卡片不会出现嵌套垂直滚动；优先让容器随内容增长。
- **图例**（切换隔离、纹理感知色块）· **工具提示** · **轴** · **数据标签**。

## Tier 1 — 人们常要求的图表
- **条形图** — 分组 + 堆叠，细条默认，水平 + 垂直。
- **折线图** — 多序列，柔和填充面积变体，无障碍标记。
- **统计卡片** — 值 + 变化量 + 可选迷你折线图（图形契约）。
- **仪表/进度条** — 同色渐变轨道。

## Tier 2 — 补充工具包
- **面积图**（堆叠，带边缘 = 折线）· **迷你折线图** · **热力图**
- **刻度图例**（顺序/发散）· **图表过滤器/时间范围** · **空状态**

## System 层 — 成为 skill
- **六项检查验证器** — `scripts/validate_palette.js`（调色板验证）。
- **主题引擎** — 将客户的色阶吸附到通过值（color-formula.md）。
- **图表类型启发式** — 选择形式（choosing-a-form.md）。
- **表格视图生成器** — 任何图表的 WCAG 无障碍等效形式。

备注：部分与整体关系由堆叠条形图承担；甜甜圈保持低优先级。
小多图是在这些之上的布局模式，不是独立组件。如果散点密集型
表面落地，散点图加入 Tier 2。
