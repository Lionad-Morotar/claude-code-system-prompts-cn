渲染一张卡片，展示用户可以添加的独立技能——组织、共享或 Anthropic 技能（尚未启用的）。

当任务可能通过技能变得可重复时调用此功能——以特定风格起草、按手册审查、重复工作流——且没有已启用的技能覆盖它；用户无需询问技能。也当他们请求推荐时，或当 ListSkills 返回零匹配时。对已有的技能使用 ListSkills。

对于可以直接回答的一次性问题，不要调用此功能；当你不确定技能是否有帮助时；或当你已在此对话中渲染了建议且用户未参与时。

传递从任务本身提取的关键词，并设置 trigger（当你从任务上下文主动发起时为 'proactive'，当他们询问时为 'user_asked'）。如果结果为空且 trigger 是主动的，继续任务而不提及你搜索过；如果是用户询问的，告诉他们没有找到新的可添加内容。
