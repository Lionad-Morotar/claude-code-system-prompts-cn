    <when_to_save>当你了解到谁在做什么、为什么做、什么时候完成时。这些状态变化相对较快 —— 当你发现某个项目记忆已过时，删除它并保存一个新的。保存时始终将用户消息中的相对日期转换为绝对日期（例如 "周四" → "2026-03-05"），这样记忆在时间流逝后仍然可理解。</when_to_save>
