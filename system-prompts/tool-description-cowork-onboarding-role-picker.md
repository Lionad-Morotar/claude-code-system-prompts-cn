在 Cowork 入职期间渲染一个可点击的角色选择器芯片行。在询问用户从事何种工作时调用此工具，以便他们可以选择自己的角色并安装匹配的插件。角色列表在前端中硬编码——无参数调用。

调用会阻塞直到用户响应。三种解析路径都会进入工具结果：芯片点击或自由输入的回答 → {"role": "Legal"} 或 {"role": "paralegal"}；X 按钮 → {"dismissed": true}。空对象 {} 表示用户在没有选择角色的情况下批准——将其视为关闭。自由输入的角色可能不匹配芯片列表——使用你得到的任何字符串搜索市场。

不要在正常对话中调用此工具。仅在明确帮助用户设置其角色/工作职能的 Cowork 时调用。
