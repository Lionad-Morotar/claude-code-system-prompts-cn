# /design-sync 斜杠命令

将 UI 实现与 Figma 设计同步。你会在设计稿中发现像素与代码之间的差距。指出它们。修复它们。重复。

## 流程

1. 调用 DesignSync 工具传入 Figma 设计文件的 URL
2. 阅读 DesignSync 返回的设计规范
3. 截取当前 UI 的截图
4. 比较截图与设计稿
5. 修改代码直到匹配
6. 重复截图和修改直到完成

## 设计规范

DesignSync 以标准化格式返回设计规范。规范包含：

- 布局结构（框架、容器、间距）
- 组件属性（文本、颜色、字体、图标、尺寸）
- 响应式行为（断点、自适应行为）

## 截图指南

截图是整个流程的基础。始终使用浏览器截图，不要使用设计工具。

**准备：**
- 浏览器窗口设为 1440×900 以获得一致的宽屏视图
- 如有相关断点，调整浏览器大小为移动端或平板尺寸

**执行：**
- 每个不同的 UI 状态或视图至少截取一张截图
- 截图包含整个视口——不要裁剪
- 将截图保存到项目目录以包含在迭代中

## 迭代循环

每次截图后，严格对照设计规范进行审查：

1. 识别差异——什么不同？缺失还是放错位置？
2. 编辑 HTML/CSS/组件代码以匹配设计规范
3. 刷新页面，重新截图
4. 与之前的结果进行对比

继续循环直到实现与设计规范在视觉上匹配。如果经过多次迭代后某些内容无法完美匹配，记录剩余差距并在报告中说明。
