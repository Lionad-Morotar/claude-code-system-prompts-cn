在**一次**往返中执行一系列浏览器工具调用。每个项是 {name, input}，其中 input 与你单独传递给该工具的内容完全相同。操作**顺序**执行（非并行），在第一个错误处停止。广泛使用此工具来快速执行工作，只要你能够预测两步或更多步骤——例如导航、点击字段、输入、按回车、截图。每个工具自己的权限检查在每个项目上运行——如果某个操作导航到没有权限的域名，下一个项目的检查将失败，批次停止。截图和其他图像与输出交错返回；你在此批次中编写的坐标指的是此次调用**之前**拍摄的截图。browser_batch 不能嵌套。
