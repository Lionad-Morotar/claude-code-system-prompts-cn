# 标记与结构

安静、深思的外观来自几个固定规范和两种负空间。数据是唯一被允许"大声"的东西。

## 标记规范（所有图表固定）

| 标记 | 规范 |
|---|---|
| 条形/柱形 | **≤ 24px 粗**（封顶 — 不填满槽位；让频段的剩余部分成为空气）；**4px 圆角数据端，基线处方形**；从单一基线生长 |
| 折线 | **2px**，圆角连接/端点 |
| 标记/端点 | **≥ 8px**（r ≥ 4），用序列颜色填充 |
| 面积填充 | 序列色相约 **10% 不透明度**（淡洗，不是饱和色块） |
| 网格线/轴 | 比表面灰深一个色阶，**细线（1px），实线**（从不用虚线），凹隐 |

## 两种间隔器（白色做分隔）

- **表面间隙。** **2px 间隙**用表面颜色分隔接触的标记 — 堆叠条形的每个分段，每个相邻条形，相同宽度。
- **表面环。** 点和端点标记携带 **2px 表面颜色环**，使它们在穿过折线或重叠时保持清晰。环是标记悬停/命中目标的一部分 — 参见 `interaction.md`。

永远不要画边框来分隔标记。间隙和环是机制；描边增加了不是数据的数据权重墨水。

## 标签与图例

**两个或更多序列时始终存在图例** — 可靠的身份通道。**单个序列不需要图例框**：只有一种颜色，标题已说明。

- **选择性标注 — 永远不要每个点上都标数字。** 标注端点、极值、或故事所关于的序列；让轴、图例和工具提示承担其余。
- **直接标签先于网格线；网格线先于第二轴。**
- **放不下的标签不被裁剪 — 先测量。** 仅在文本有舒适内边距时才放在标记内部。放不下则移到条形外端或工具提示。永远不要 `overflow: hidden`。
- 条形 → 值在尖端。柱形 → 值在顶部。折线 → 值在端点。
- Y 轴刻度：取整为干净数字，千位逗号分隔。
- **文本永远不穿数据颜色。** 标记携带序列颜色；标签、值、图例使用**文本标记**（主要/次要/弱化）。身份来自文本*旁边*的彩色标记。例外：彩色填充内部的标签根据亮度选白或墨色。
- **当端标签碰撞时，不要堆叠。** 使用**引导线**、**小多图**，或退回图例 + 工具提示。超过约 4 个汇聚序列，小多图通常是对的。

## 数字 — 当形式是一个数字时

- **统计卡片**契约：`label`（句首大写，无尾随冒号）· `value`（Sans semibold，自动紧凑）· `delta`（可选；有符号，颜色=方向×上升是否好）· `trend`（可选；迷你折线图）。
- **仪表：** 填充承载严重程度；未填充轨道是**同色渐变的较浅阶梯**。
- **主数字。** 仪表盘首屏展示的单数字，≥48px，使用与其他内容相同的无衬线体（永远不用展示体或衬线体）。每个视图恰好一个。
- **大数字用比例数字；仅列中用等宽数字。** 大型独立值使用字体默认比例数字；`font-variant-numeric: tabular-nums` 保留给必须垂直对齐的数字列（表格行、轴刻度）。

## 纹理 — 备用通道（可选）

当色相失败时 — 完整 CVD、灰度打印、`forced-colors` — 纹理承载身份。一种方向性手绘填充，仅用 **45° 及其 135° 镜像**（永远不水平/垂直 — 那些看起来像网格线/条形）。墨色同色调（来自填充自身渐变的较深阶梯），各槽位等响度。在值刻度上纹理是*有序的*（旋转随量值变化；臂角承载发散符号）。由无障碍设置、打印或 `forced-colors` 触发 — 默认不启用。（参见 `palette.md`。）
