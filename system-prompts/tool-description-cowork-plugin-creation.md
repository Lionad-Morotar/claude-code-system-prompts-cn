创建自定义的 Cowork 插件。Cowork 插件允许你通过定义组件、配置和 MCP 服务器来扩展 Claude Code 的功能。插件创建过程包括：定义插件的元数据、组件模式、示例配置，以及可选的 MCP 服务器发现与连接配置。创建完成后，插件可以发布到市场供其他用户使用。
