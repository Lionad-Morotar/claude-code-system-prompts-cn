长篇文档布局：暖色纸张背景上的衬线正文字体，带报头、目录、散文章节和可选附录。适合打印。

## 使用方法

1. 从此技能的基础目录（上方列出）读取 `template.html`。
2. 将其复制为起点。将每个 `<!-- SLOT: ... -->` 标记替换为真实内容 — 每个槽位内的注释描述了应填入的内容。每个槽位在注释后还有占位文本（示例标题、标题、句子、要点、目录条目）；也需替换这些文本 — 仅移除注释标记会留下占位内容在发布页面中。
3. 自检填充后的 HTML：无残留 `SLOT` 标记，无遗留占位文本，每个目录（TOC）条目指向存在的 section id。
4. 发布前进行样式和内容的后续调整。模板提供默认结构和样式，而非强制要求：精简散文，调整样式以适配文档需求 — 重新调整 `--cds-*` 令牌值（在声明它们的每个作用域中 — 亮色 `:root` 块、两个暗色作用域和 `@media print` 块 — 否则值在暗色模式或打印中会回弹），重新设计组件样式，或在内容需要时重组（保持文本对比度可访问，三个或更多章节的报告保留目录）。
5. 使用 `Artifact` 工具发布填充后的 HTML。

**仅限创建。** 编辑现有报告工件时，直接操作其当前 HTML — 不要重新读取或重新应用此模板。

## 槽位

| 槽位 | 填入内容 |
| --- | --- |
| `TITLE` | 文档的中心论点或主题。 |
| `SUBTITLE` | 一句话说明关键发现或范围。 |
| `KEY_TAKEAWAYS` | 可选 — 3–5 个项目，**每个一行**：一个携带编号或具体内容的子句，无子句或第二句话。这是低于 SUBTITLE 单句的项目级别；不要重述它，也不要将项目填充为段落。短文档可省略整个 `<aside class="takeaways">`。 |
| `TOC_ITEMS` | SECTIONS 中每个 `<h2>` 一个 `<li><a href="#id">章节标题</a></li>`。在编写 SECTIONS **之后**填写，基于你实际写的标题。模板中的一个小脚本从渲染的章节重建列表，因此锚点在屏幕上自动修复 — 静态列表是脚本不运行时的后备。 |
| `SECTIONS` | 每个主要主题一个 `<section id="...">`，各有 `<h2>` 和正文散文。使用 `<h3>` 表示子章节，`<table>` 表示结构化数据，`<pre>` 表示代码，`<blockquote>` 表示旁注，`<figure>` + `<figcaption>` 表示图表。每个章节以其结论开头。 |
| `APPENDIX` | 可选 — 会打断主流程的支撑材料。不需要时省略整个 `<section class="appendix">`。 |

模板还有一个用于报头眉标的次要内联槽位（文档类型 / 日期）— 在原位标注。

## 内容

尊重读者的注意力 — 它是报告消耗的最稀缺资源：

- 以最重要的内容开头。副标题携带标题发现，要点携带最重要的细节，每个章节以结论开头；细节、方法论和原始数据在后 — 或放入附录。
- 清晰简洁地写作：通俗语言、短句，每个术语在首次使用时定义，无未解释的缩写。删除任何不改变读者认知或决策的内容。
- 说明证据是什么以及每个论断的确定程度：区分已测量的、推断的和推测的，而非以相同语气呈现三者。
- 当图表比散文更能说明问题时使用 — 趋势、比较、结构。将图形绘制为 `<figure>` 内的自包含内联 SVG，绝不作为外部图片（工件必须在无网络访问下渲染），并为每个图形添加说明读者应从中获取什么的 `<figcaption>`。

## 注释

- 模板是 **body 片段** — 无 `<!DOCTYPE>`/`<html>`/`<head>`/`<body>` 包装。Artifact 工具在发布时添加自己的骨架。
- 以完整句子撰写真实散文。布局针对约 65 字符行宽调优。
- 样式默认值为内联 `--cds-*` 自定义属性（自包含 — 工件在无网络访问下渲染），在亮色 `:root` 块中声明并在两个暗色作用域和 `@media print` 块中重新声明。它们是默认值而非强制：在后续调整中，在声明它们的每个作用域中重新调整，或完全重新设计。
