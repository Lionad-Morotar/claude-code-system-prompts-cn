# 交互 — 工具提示与过滤器

HTML 图表默认是交互式的 — 悬停层是交付物的一部分，
不是升级。省略它是例外（纯统计卡片），永远不是默认。
用与静态渲染同等的精心设计来设计它。

## 工具提示与悬停

工具提示**增强，从不限制**：工具提示显示的每个值也可以
不用它获取，通过直接标签或表格视图。键盘焦点与悬停
显示相同细节。

- **十字线追踪 X。** 一条垂直细线跟踪指针并吸附到
  最近的数据位置。读者瞄准的是日期，而非 2px 的线。
- **在条形和单元格上，标记就是命中目标。** 无十字线 — 每个条形、分段、
  点或热力单元格携带自己的 `pointermove`/`focus` 工具提示显示类别和
  值，悬停的标记微微抬起（轻微提亮或描边）使读者看到响应。
- **一个工具提示，所有序列。** 读数列出该 X 位置的每个序列 —
  指针不需要精确落在折线或填充上才能获取值。
- **标签是不可信数据 — 使用 `textContent`。** 序列和类别名称
  通常来自 CSV 表头、工具输出或 API 响应。将它们插入
  工具提示/图例/表格 DOM 时使用 `textContent` 或 `createTextNode`，
  永远不要通过 `innerHTML` 字符串拼接。
- **值在前，标签在后。** 在工具提示中值是主要的高对比度
  元素，序列名称是次要的 — 图例的层级被反转，
  因为这里读者有序列，需要的是数字。
- **线段键，不是方块。** 工具提示行用序列颜色的短线段标识序列；
  在工具提示密度下，填充方块是做标签工作的数据权重墨水。
  （图例仍然镜像标记：条形/面积用矩形，折线用线段。）
- **命中目标比标记大。** 标记的悬停/焦点区域包含其
  2px 表面间隙甚至更大 — 永远不只是绘制的像素。8px 散点是
  没人能可靠命中的精确目标；给每个点至少 **24px** 的透明命中区域，
  或者 — 对于密集散点 — 使用最近点/Voronoi 层使指针只需要
  *最接近*，而非精确中心。（十字线已经对折线和条形图的 X 做了这个；
  散点和气泡需要逐点版本。）
- **被推出标记的值活在工具提示中。** 当标签放不进
  小条形时（参见 `marks-and-anatomy.md`），该条形的命中区域在悬停和
  焦点时携带值 — 工具提示是它的溢出之家，表格视图保持
  无需悬停即可访问。

## 过滤器与时间范围

每个监控仪表盘都需要相同的控件。这些是**标准 UI，不是
图表标记** — 用与图表装饰匹配的普通 HTML 表单控件构建它们。
数据可视化只添加组合规则：

- **一行，在图表上方。** 过滤器位于其所作用范围上方的
  单行左对齐中 — 永远不在图表卡片内，永远不是每图表独立。
  如果一个图表需要自己的范围，那是另一个仪表盘。
- **日期范围优先。** 它是每个读者首先使用的过滤器；预设（今天、
  最近 7/30/90 天）在自定义范围之前。
- **过滤器作用于其下方所有内容。** 每个图表、统计和表格对
  同一切片重新渲染，数字始终一致。
- **重新获取保持画面。** 数据重新加载时，图表以保持
  降低不透明度的上一次渲染 — 无骨架、无布局跳动、无闪烁。

好的日期选择器将预设列为行（没人用日历网格
来选"最近 30 天"），用 16px 粗体勾选标记选择，悬停保持为
幽灵色使其从不与选择竞争，自定义范围藏在页脚细线后面。
（参见 `palette.md` 获取参考规范。）
