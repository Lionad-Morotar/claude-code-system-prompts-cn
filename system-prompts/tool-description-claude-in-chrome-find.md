使用自然语言查找页面上的元素。可以按元素用途搜索（如"搜索栏"、"登录按钮"）或按文本内容搜索（如"有机芒果产品"）。返回最多 20 个匹配元素及其引用，这些引用可供其他工具使用。如果匹配超过 20 个，你会收到通知，请使用更具体的查询。如果你没有有效的标签页 ID，请先用 tabs_context_mcp 获取可用的标签页。
