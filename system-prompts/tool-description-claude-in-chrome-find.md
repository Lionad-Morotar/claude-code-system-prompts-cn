使用自然语言在页面上查找元素。可以按元素的用途（例如"搜索栏"、"登录按钮"）或文本内容（例如"有机芒果产品"）进行搜索。最多返回 20 个匹配元素，并附带可用于其他工具的引用。如果匹配项超过 20 个，会提示你使用更具体的查询。如果你没有有效的标签页 ID，请先使用 tabs_context_mcp 获取可用标签页。
