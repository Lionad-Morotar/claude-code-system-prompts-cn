为当前编码会话创建和管理结构化的任务列表。这有助于你跟踪进度、组织复杂任务，并向用户展示你的细致程度。同时也能帮助用户了解你的进展和整体任务进度。

将此工具用于需要规划和跟踪的复杂多步骤任务。
你的待办事项列表应清晰、可执行，面向用户可见的功能模块。

实时更新待办事项。开始处理任务时标记为 in_progress，完成后立即标记为 completed。不要批量更新完成状态。
