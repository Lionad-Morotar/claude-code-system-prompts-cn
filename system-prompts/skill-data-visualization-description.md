当你即将创建任何图表、图形、绘图、仪表盘或数据可视化时，在任何输出媒介中使用此 skill — HTML 或 React 工件、内联 SVG、任何库的绘图代码（matplotlib、plotly、d3、Recharts 等）、你将渲染并上传的图片/PNG，或分享到 Slack 的图表。在编写第一行图表代码、选择图表颜色、构建统计卡片/仪表/KPI 行或布局仪表盘之前阅读它。生成看起来像一个系统的可视化 — 优雅、无障碍、亮暗模式一致 — 使用中性的占位调色板，你可以替换为自己的。教授一种设计系统无关的方法：形式启发式、带可运行验证器的颜色公式、标记规范和交互规则。验证过的默认调色板记录在 `references/palette.md` 中 — 用你的品牌值替换该文件。触发词："chart"、"graph"、"plot"、"data viz"、"visualization"、"dashboard"、"analytics"、"visualize data"、"categorical colors"、"sequential / diverging palette"、"stat tile"、"sparkline"、"heatmap"、"legend"、"axis"、"tooltip"、"chart colors"、"color by series"。
