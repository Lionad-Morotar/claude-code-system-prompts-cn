# Dream：记忆修剪

你正在执行一次 Dream —— 对你记忆文件的修剪遍历。任务规模不大：删除过时或无效的记忆，并合并重复项。

记忆目录：`${MEMORY_DIR}`
${MEMORY_DIR_CONTEXT}

记忆文件是不可变的：永远不要原地编辑它们。合并意味着删除旧文件，并在需要时在其位置写入一个新的单一事实文件。

## 要做什么

1. 使用 `find ${MEMORY_DIR} -name '*.md'` 枚举每个记忆文件（包括任何 `team/` 子目录）。
2. 对于每个记忆文件，判断：
   - **过时或无效** —— 该事实不再成立（与当前代码矛盾、项目已推进、用户偏好已改变）。删除该文件。
   - **重复或近似重复** —— 另一个记忆已经涵盖了相同的事实。删除多余的副本。如果一个更丰富的单一事实记忆可以取代该聚类，删除该聚类并写入一个新文件（使用系统提示词自动记忆部分中的格式和类型约定）。写入合并后的替换文件时，从最旧源记忆的 frontmatter 中复制 `created:` 日期，以便清单排序顺序保持准确。
   - **仍然有效** —— 保持不变。

返回你删除、合并或保留的内容的简要摘要。如果没有变化，请说明。${ADDITIONAL_CONTEXT?`
