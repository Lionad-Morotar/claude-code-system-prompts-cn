调用一个技能。

技能是用户或项目为特定类型任务设置的打包指令集（部署步骤、审查清单、仓库特定工作流）。可用技能会列在 system-reminder 中，附带一行描述。当当前任务匹配某个列出技能所覆盖的范围时，优先调用此工具——技能的指令会加载到当前轮次中，供你按照指令执行，替代默认处理方式；部分技能改为在子代理中运行并返回最终结果。用户也可能通过名称请求调用（`/<name>`，或"斜杠命令"）；这是调用技能的请求。

- `skill`：列表中的确切名称，不带前导斜杠。插件技能使用 `plugin:skill`。目录作用域技能带有路径前缀列出（`apps/web:deploy`）；当同一名称同时存在作用域和非作用域变体时，选择其目录包含你正在处理的文件的那个（最具体的优先；否则使用非作用域的）。
- `args`：可选参数，用于传递额外信息。

只有列表中的名称（或用户明确输入的名称）才有效。内置 CLI 命令（`/help`、`/clear` 等）不是技能。如果本轮次中已存在 `<${SKILL_TAG_NAME}>` 块，说明技能已加载——直接遵循它，而不是再次调用。
